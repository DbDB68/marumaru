# 庭院可走原型

按 2026-09-05 的 marumaru1 布局草图制作，保留西侧建筑群、东北花树环路、池塘和南侧庭园的大致关系。当前是色块原型，建筑用途仅接入已有房间，其余轮廓待后续确认。

- F5 从庭院缘侧外开始。WASD / 方向键移动，Z 搭话。
- 五个标记入口通往主屋、厨房、缘侧、手合场和田地；各房间有返回庭院的出口。保留主屋通厨房/缘侧、缘侧通手合场的室内连接。
- 草地可自由行走，建筑、水面和树干有碰撞。溪流东侧木桥可以通行，池塘斜桥连接两岸，可双向通行。
- 庭院尺寸 1280 × 1120，镜头跟随人物并限制在地图内；室内保持原尺寸。
- 日程保持原时间和对白，只调整庭院活动坐标。NPC 仍使用原有据点附近随机散步，没有新增跨地图寻路。

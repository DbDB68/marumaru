# marumaru

《刀剑乱舞》同人陪伴小游戏 · Godot 4.7 + GDScript · 像素风

一座自己运转的本丸：刀剑男士们按日程生活——吃饭、赖床、扫庭院、闲聊，
他们的人生不为玩家暂停。玩家是偶尔上线的观察者：打开看一眼他们今天在干啥，
能聊两句，但世界照样转。

方向是「不用自己种地的星露谷物语」。先让他们活起来，再让玩家介入。

## 跑起来

需要 Godot 4.7（开发时用的是 4.7.2-stable）：

1. 克隆本仓库；
2. 用 Godot 编辑器导入 `project.godot`；
3. F5 运行，主场景是庭院。

无头冒烟：

```bash
godot --headless --path . --quit-after 60
```

回归测试脚本在 `tools/` 下（对话、日程、远征、小剧场、地图连通性等），
跑法见 [AGENTS.md](AGENTS.md)。

## 想改点什么

- 刀男日程在 `data/schedules.json`，可以直接手改：什么时间在哪个房间、做什么、说什么；
- 双人小剧场对白在 `data/interactions.json`，键按字典序 `id1+id2`；
- 新刀男入住 = 日程加一段 + `scenes/npcs/<id>.tscn` + 一张皮
  （占位素材由 `tools/gen_placeholders.py` 生成）。
